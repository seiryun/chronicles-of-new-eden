# Chronicles of New Eden

An independent, non-commercial EVE Online fan archive.

## Pages
- `index.html` — home
- `seiryun.html` — Seiryun, the Rogue Cultivator
- `agaroth.html` — Agaroth Ethriael, the Old Wolf of New Eden
- `lenora.html` — Lenora, Guardian of the Fleet
- `archives.html` — origins and historical records
- `about.html` — project information and fan disclaimer

## Publish with GitHub Pages
1. Upload the contents of this folder to the root of your GitHub repository.
2. In repository Settings → Pages, choose Deploy from a branch.
3. Select `main` and `/(root)`, then save.
4. Wait for GitHub Pages to publish the site.

All videos are muted by default and have controls. The project is non-commercial and requests no payments or in-game donations.
